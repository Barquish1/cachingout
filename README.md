# Caching Out

Free WordPress caching plugin: page caching served before WordPress loads,
browser caching and compression, and lazy loading, switched on at
activation. Visitors from social and ad links (fbclid, gclid, utm_ and the
like) get the cached page too. Logged-in visitors and carts are never cached,
and another cache plugin's files are never overwritten.

**Install it from WordPress.org:** https://wordpress.org/plugins/cachingout/
(Plugins > Add New in your WordPress admin, search "Caching Out").

## About this repository

This is a read-only mirror. Each release is copied automatically from
WordPress.org, so the files here are exactly what every site downloads, one
commit and one `v<version>` tag per release. Development happens elsewhere;
pull requests here cannot be merged.

- **Help and bug reports:** the plugin's support forum,
  https://wordpress.org/support/plugin/cachingout/
- **Documentation and changelog:** https://cachingout.com/docs/
- **Caching Out Pro** (a separate paid add-on): https://cachingout.com/pricing/

Results vary by host, theme and plugin mix.
